# docs/

- `PLAN.md` (repo root): master plan, workstreams, milestones.
- `CONTRIBUTING.md` (repo root): how parallel workstreams branch, merge, and avoid conflicts.
- [`ethics.md`](ethics.md): purpose, what the reconstruction will and will
  not depict, how footage of people is handled, family/rights-holder
  requests, language guidelines, how contested claims are treated.
- [`licensing.md`](licensing.md): code license (Apache-2.0), the fair-use
  basis for processing footage, per-source license tracking, which
  outputs are redistributable and under what license, attribution, DMCA/
  takedown process, contributor licensing (DCO).
- [`methodology.md`](methodology.md): the pipeline end to end for
  investigators — conventions (ENU, `c2w`, project seconds, epochs),
  uncertainty representation and propagation, tracing a claim back to
  source frames, registering your own footage, known limitations, a
  defensible-claim checklist.
- [`sources_overview.md`](sources_overview.md): prose tour of the major
  public footage/imagery sources (TV archive, NIST FOIA release,
  Wikimedia, Flickr, documentaries, photographers, NOAA/USGS, NIST NCSTAR,
  NYC open data) and what each is good for.
- [`onboarding.md`](onboarding.md): setup, repo layout, workstream
  ownership map, how to pick up a task, glossary.
- [`faq.md`](faq.md): common questions (is this a conspiracy project?, why
  not photogrammetry?, court/journalism use, timing accuracy, where's the
  footage, submitting your own footage).
- `docs/ethics.md`, `docs/licensing.md`, `docs/methodology.md`,
  `docs/onboarding.md` are owned by the `docs` workstream; see
  `CONTRIBUTING.md` for the full ownership table.
- Project-wide `CODE_OF_CONDUCT.md` and `SECURITY.md` live at the repo
  root; issue/PR templates live under `.github/`.
- Each package has its own `README.md` with usage and design notes.
